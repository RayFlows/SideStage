1. 在「高级设置 → 分身启动项」新增「全部打开」和「全部关闭」。操作前会显示影响数量，完成后列出成功、跳过和失败的项目数。「全部打开」会撤销分身的跳过规则，并保留你在 Windows 中设置的禁用状态。
2. 修复部分个人启动项无法切换的问题。以管理员身份运行 SideStage 后，可以调整需要管理员权限才能修改的个人登录任务。普通权限运行时，「分身登录时启动」标题旁会显示三角提示，说明隐藏了哪些开关。
3. 遇到登录任务引用失效账户时，会显示原账户和当前账户，由你确认是否修复。批量操作时可以逐项勾选。修复后，任务将继续使用你确认的账户。
4. 修复启动项列表刷新后行距变大的问题。卸载时会逐项恢复并核对原启动入口。遇到恢复失败的项目会保留备份和失败清单，处理后可重试卸载。
