SideStage 首个正式版，适用于 Windows 10 / 11 x64。已安装 0.1.0-beta.9 的用户可以直接覆盖升级。本版沿用 beta.9 的应用功能。

1. 在独立窗口连接本机 Windows 子会话。首页分别显示子会话状态和当前窗口的 RDP 连接状态。需要保留分身里的程序时，请在高级设置中选择「断开连接」。
2. 在高级设置中调整分辨率、缩放和静音。需要自动登录时，可将账户密码保存在本机 Windows 凭据管理器。
3. 从另一台电脑断开远程桌面后，实验性会话恢复会尝试把主桌面接回本机控制台。本机显示器可能直接显示主桌面，可在「高级设置 → 会话恢复」关闭此功能。主动按 Win + L 锁屏时会保留锁定状态。
4. 首次安装请下载 `SideStage-0.1.0-Setup-x64.exe`，安装包已包含 .NET 运行时。已安装的用户可在「高级设置 → 应用更新」选择 CNB 国内源或 GitHub 下载更新。
