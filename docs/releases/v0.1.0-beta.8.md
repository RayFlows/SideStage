1. 新增实验性会话恢复。从另一台电脑断开远程桌面后，如果原分身仍在运行但无法接收输入，SideStage 会尝试把当前账户的主桌面接回空闲的本机控制台，再次检查分身输入，并把结果写入活动日志。接回后，本机显示器可能直接显示主桌面。此功能默认开启，可在「高级设置 → 会话恢复」中关闭。主动按 Win + L 锁屏会保留锁定状态。[查看 Issue #5](https://github.com/RayFlows/SideStage/issues/5)
2. 主窗口会记住关闭前的大小。最大化关闭后，下次仍以最大化打开。最小化关闭后，下次按最小化前的状态打开。更换显示器或缩放比例后，SideStage 会按当前屏幕的可用空间调整尺寸。[查看 Issue #2](https://github.com/RayFlows/SideStage/issues/2)
