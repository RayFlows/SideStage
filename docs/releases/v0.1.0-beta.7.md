1. 整理安装目录。主程序、会话代理和更新器各自打包所需依赖。从 beta.6 覆盖升级后，安装目录顶层的 DLL 从 221 个减至 0 个。安装器会自动清理旧版原样分发的文件，保留用户添加或修改的文件。
2. 区分下载和安装进度。更新包下载并校验完成后，点击「安装并重启」即可查看实际安装进度。安装完成后会自动重新打开 SideStage。下载和安装进度条统一采用黄铜色。
3. 增加待安装提醒。后台下载完成后，首页会显示「设置 · 待安装」，也可以从高级设置里的「查看待安装更新」继续安装。
4. 修复标题栏按钮高亮残留。窗口从最小化恢复，或在最大化和还原之间切换后，标题栏按钮会根据鼠标当前位置正确显示悬停状态。
