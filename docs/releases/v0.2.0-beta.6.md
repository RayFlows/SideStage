1. 修复了“安装并重启”后可能以普通权限打开的问题。新版会沿用“启动时请求管理员权限”的设置。安装前若有其他进程占用程序文件，SideStage 会保留当前窗口并提示占用进程，关闭后即可重试。
2. 首次连接时，如果还没有保存登录凭据，会直接打开“登录凭据”页。之后再连接，可以选择配置凭据，也可以直接连接并勾选“不再提示”。删除已保存的凭据后再直接连接，也会清除 RDP 控件中上次使用的账户信息。
3. 统一了应用内确认和错误弹窗的样式，包括删除凭据、注销子会话、批量调整启动项和断开连接以安装更新时的提示。
4. 活动日志默认保留 14 天。单个文件达到 2 MiB 时换新文件，超过 32 MiB 或 128 个文件时优先清理最旧的记录。侧栏显示最近 500 条，可从活动日志旁的 ⓘ 打开日志文件夹。过期的安装日志和重启错误日志也会自动清理。
