1. SideStage 启动时默认请求管理员权限，方便远程桌面断开后自动接回主桌面。在 Windows 授权提示中选择「否」，本次仍可以普通权限使用。可在「高级设置 → 启动权限」关闭此选项，下次启动生效。
2. 首页环境检查新增「运行权限」，并将「当前子会话」与「RDP 连接」分开显示。现在可以看清分身是否仍在运行，以及当前窗口是否已连接到它。
3. 管理员模式下的更新窗口新增「以普通权限更新」入口。通过启动授权进入管理员模式后，可从这里切换到普通权限，选择下载来源并安装更新。若当前已连接，SideStage 会先询问是否断开，确认后保留子会话。
4. 优化首页和高级设置的渲染，减少打开窗口、展开侧栏和拖动边框时的重复绘制。本机测试中，首页调整窗口大小的单步中位耗时从 22.3 毫秒降至 17.3 毫秒。
