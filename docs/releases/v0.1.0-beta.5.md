从 0.1.0-beta.4 升级：请从发布页下载本版 x64 安装包，直接覆盖安装，无需先卸载或重新填写登录凭据。从本版起，后续更新可以在 SideStage 内完成。

1. 应用内更新：在「高级设置 → 应用更新」可查看更新说明，选择 CNB（国内推荐）或 GitHub 下载安装包。长说明会在框内自动换行；暂时不想更新，可以选「稍后」或「跳过此版本」。
2. 更新时保留子会话：下载完成后不会自动安装。点「重启并更新」时，如果 RDP 仍在连接，SideStage 会先询问是否断开。确认后只断开连接，不注销子会话。
3. 远程桌面快捷键：点击 RDP 画面后，Alt+Tab 在子会话里切换窗口，Win 键打开子会话的开始菜单，不再切回主桌面。
4. 显示缩放：放大 Windows 显示比例后，首页环境检查会随文字加宽、增高，每项保持一行；小窗口可以横向滚动查看完整内容。设置侧栏的按钮、输入框和滚动条也会随比例调整，100% 缩放下仍保持紧凑。
5. 侧栏与密码输入：收起按钮移到侧栏左边缘的中间，不用滚到底部。密码遮盖圆点变小，点输入框旁的眼睛即可核对刚输入的密码；离开凭据页后会恢复遮盖。
6. 安装目录：顶层文件夹从 15 个减到 4 个，不再铺开 11 个用不到的语言目录。保留简繁中文资源，安装包仍自带 .NET，断网也能安装。

提示：如果启动检查后首页显示「设置 · 有更新」，但没有弹出更新窗口，可进入「高级设置 → 应用更新」，点击「查看可用更新」，不必重启。
