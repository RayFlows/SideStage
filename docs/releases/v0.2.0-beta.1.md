1. 高级设置新增「分身启动项」。首次打开会扫描本机启动项，之后可查看上次结果、手动刷新，或开启「启动时自动扫描」。列表中可单独选择哪些应用随分身登录启动，也可以展开只读项目查看原因。
2. 新增「接受测试版更新推送」。首次安装 Beta 时默认开启，正式版默认关闭，之后沿用你的选择。点「跳过此版本」只会跳过当前版本，下一版本仍会提示。手动检查可以找回已跳过的版本。
3. 普通权限运行时，「远程断开后接回主桌面」会关闭并显示权限提示。下次以管理员身份启动时，会恢复你保存的选择。
4. 调整高级设置的分组和间距。「当前会话」在连接时排在最上方。从打开的侧栏发起连接时，会先收起侧栏再连接。

已安装 v0.1.0 正式版的用户可以从发布页下载 Windows x64 安装包覆盖升级，加入本轮测试。
